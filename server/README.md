# 트리즈엔 홈페이지 — 서버 설치 안내

이 폴더(`server/`)를 그대로 웹 호스팅에 올리면 홈페이지와 관리자 화면이 동작합니다.
현재 www.trizn.kr 과 같은 **Apache + PHP** 호스팅을 기준으로 만들었습니다.

## 필요한 환경
- PHP 8.0 이상 (PDO, fileinfo 확장 — 대부분의 호스팅에 기본 포함)
- 데이터베이스: 기본은 **SQLite**(따로 DB를 만들 필요 없음). MySQL을 쓰려면 `config.php` 에서 바꿉니다.

## 설치 순서
1. `server/` 폴더 안의 파일 전체를 FTP로 홈페이지 루트(예: `public_html/` 또는 `www/`)에 올립니다.
   숨김 파일 `.htaccess`, `.user.ini`, `data/.htaccess`, `uploads/.htaccess` 도 함께 올라가야 합니다.
2. `data/` 와 `uploads/` 폴더에 쓰기 권한을 줍니다 (FTP 프로그램에서 권한 755 또는 호스팅 안내에 따라 777).
3. (권장) 올리기 전에 `config.php` 의 `install_key` 에 아무 문자열이나 넣어 두면, 설치할 때 그 키를 알아야만 설치됩니다.
4. 브라우저에서 `https://www.trizn.kr/install.php` 를 엽니다.
   최고관리자 아이디·이름·비밀번호를 정하고 **설치하기**를 누르면 기본 콘텐츠(지금 사이트 내용)가 함께 들어갑니다.
5. 설치가 끝나면 **`install.php` 파일을 서버에서 지웁니다.** (지우지 않아도 다시 설치되지는 않지만, 지우는 편이 안전합니다)

## 관리자 접속
- 주소: `https://www.trizn.kr/admin` (또는 홈페이지 맨 아래 "관리자" 링크)
- 아이디/비밀번호로 로그인합니다. 2시간 동안 아무 작업이 없으면 자동 로그아웃됩니다.
- 같은 아이디로 15분 안에 5번 틀리면 15분 동안 로그인이 막힙니다.

## 관리자 계정과 권한
- **최고관리자**: 모든 메뉴 + `관리자 계정` 메뉴에서 계정을 만들고, 권한을 정하고, 정지·삭제합니다.
- **서브관리자**: 최고관리자가 고른 담당 메뉴만 관리자 화면에 보이고 저장할 수 있습니다.
  권한은 서버(api.php)에서 매번 확인하므로, 화면을 조작해도 담당하지 않은 메뉴는 바뀌지 않습니다.
- 비밀번호를 잊으면 최고관리자가 해당 계정의 `수정`에서 새 비밀번호를 넣어 줍니다.
- 최고관리자는 항상 한 명 이상 남아 있어야 합니다.

## 영상·파일 업로드 한도
- 기본 한도는 512MB입니다 (`config.php` 의 `max_upload_mb`).
- 실제 한도는 호스팅의 PHP 설정(`upload_max_filesize`, `post_max_size`)을 넘을 수 없습니다.
  `.htaccess`(Apache 모듈형 PHP)와 `.user.ini`(PHP-FPM)에 512MB로 올려 두었지만, 호스팅에서 막아 둔 경우가 있습니다.
  관리자 화면의 한도 안내가 원하는 값보다 작으면 호스팅 고객센터에 PHP 업로드 한도 변경을 요청하세요.
- 한도보다 큰 영상은 관리자 화면에서 브라우저 압축 후 업로드를 고를 수 있습니다.

## 백업
- SQLite 사용 시: `data/trizn.sqlite` 파일과 `uploads/` 폴더를 내려받아 두면 전체 백업입니다.
- MySQL 사용 시: DB 덤프 + `uploads/` 폴더.

## MySQL로 바꾸려면
`config.php` 에서
```php
'db_dsn'  => 'mysql:host=localhost;dbname=DB이름;charset=utf8mb4',
'db_user' => 'DB아이디',
'db_pass' => 'DB비밀번호',
```
로 바꾼 뒤 install.php 를 실행하면 표가 자동으로 만들어집니다.

## 화면을 고친 뒤 다시 만들기 (개발자용)
홈페이지 화면 원본은 저장소의 `site/index.html` 입니다. 고친 뒤 저장소 루트에서
```bash
python3 tools/build_server.py
```
를 실행하면 `server/index.html` 이 다시 만들어집니다.
