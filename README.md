# 트리즈엔(TrizN) 홈페이지 리뉴얼

- `site/index.html` — 공개 홈페이지 + 관리자 CMS (`#admin`) 단일 페이지
- `site/seed/` — 초기 콘텐츠 데이터 (기존 trizn.kr 문구 기반)
- `site/logo.png`, `site/logo-white.png` — 로고

관리자 화면에서 저장한 내용은 데이터베이스에 기록되고, 열려 있는 홈페이지에 즉시 반영됩니다.
모든 목록(메뉴, 메인 비주얼, 팝업, 사업영역, 솔루션, 인증, 게시판, 연혁, 파트너사)은 드래그 또는 ▲▼ 버튼으로 순서를 바꿀 수 있습니다.
